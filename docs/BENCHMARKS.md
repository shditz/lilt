## Methodology

When benchmarks are conducted, they will follow this methodology:

1. **Baseline:** Vanilla Minecraft 26.3 with Fabric API only
2. **Test:** Same configuration with Lilt installed
3. **Metrics:** Average FPS, P95 frame time, P99 frame time, 1% low FPS, heap usage
4. **Duration:** 5-minute sessions in consistent test worlds
5. **Hardware:** Documented CPU, GPU, RAM, JVM flags

Results will not be fabricated. Only actual measured data will be reported.
